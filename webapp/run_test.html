🧪 Run Tests

Batch-evaluate a trained model and compare its prediction to the stored label.

Runs the selected model over a set of labelled images (the same preprocessing & calibration as a single prediction) and reports predicted vs. expected Total_Score per image plus aggregate error. Drawn / Uploaded images are your own test set (not used in training); the training sources are shown for reference but are optimistic (the model has seen them).
