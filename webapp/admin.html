🧹 Clean Temporary Files

Delete all scratch under /app/data/tmp — every file and all subfolders (preview images, coreg/synth outputs, etc.). Safe — does not touch the database, models, or visualizations.

🗑️ Reset Database

Destructive. Drops and recreates all tables and clears visualizations — every imported/labelled image and all in-DB data is permanently deleted (trained model files on disk are kept). Re-import afterwards with import_unified.py. Type RESET_ALL_DATA to enable the button.
