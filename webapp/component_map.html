Define The canonical geometry of the 20 elements is hand-traced on the reference figure (paint each element's region below), derived from the official scoring manual. Check The per-element heatmaps below are an independent sanity check that the labels and the model agree on where each element lives — data-driven (mean ink | presence=1 − presence=0, within each Total_Score band, then averaged; model-free) and Grad-CAM (the component CNN's presence-logit attention averaged over ~250 real TELEFRED drawings, layer3). Bright peak = the element's location; the faint halo is residual from slight figure-to-figure misalignment.

✏️ Annotate elements — paint each element's region by hand
Pick an element below, then paint over its region on the figure with the brush (drag the mouse / finger). Works for the circle, star and cross too — just cover the shape. The painted region is intersected with the figure's ink to recover that element's exact strokes, giving a clean 20-element definition (in the correct 568×274 frame) for structured low-score generation.
